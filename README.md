# Módulo 1 — Análise e Preparação de Dados

Este módulo reúne as atividades desenvolvidas ao longo de quatro unidades, acompanhando diferentes etapas do processo de **Análise de Dados** aplicado à base de acidentes da **Polícia Rodoviária Federal (PRF) — 2025**.

## Estrutura do módulo

```text
Módulo 1/
│
├── Unidade 1/
├── Unidade 2/
├── Unidade 3/
└── Unidade 4/
```

Cada pasta corresponde a uma unidade e reúne os arquivos e materiais produzidos em cada etapa do projeto.

## Sobre o módulo

As atividades percorrem diferentes etapas do processo, desde a **compreensão do problema de negócio** até a **exploração, análise, tratamento e preparação dos dados para modelagem**.

### Unidades

* **Unidade 1 — Compreensão do Negócio:** definição do contexto, problema e objetivos da análise, seguindo a etapa de compreensão do negócio do CRISP-DM;
* **Unidade 2 — Tratamento e Análise dos Dados:** organização, exploração e visualização da base utilizando Excel, tabelas dinâmicas e gráficos;
* **Unidade 3 — Análise de Dados com SQL:** consultas, agregações e análises da base utilizando SQL e SQLite, com geração de resultados em CSV;
* **Unidade 4 — Tratamento e Preparação dos Dados:** tratamento e padronização da base utilizando Python e Pandas, com geração das bases analítica e modelável.

O conjunto das atividades demonstra a evolução do projeto e a aplicação de diferentes ferramentas e técnicas de Análise de Dados, partindo da definição do problema e avançando até a preparação dos dados para modelagem.
