# Unidade 4 — Tratamento e Preparação dos Dados

Nesta unidade foi realizada a preparação da base de acidentes da **Polícia Rodoviária Federal (PRF) — 2025**, utilizando Python e Pandas.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `BasePRF2025.ipynb` | Notebook com o tratamento dos dados |
| `dados_abertos_prf-datatran2025.csv` | Base bruta da PRF |
| `base_analitica_prf_2025.csv` | Base tratada para análise |
| `base_modelavel_prf_2025.csv` | Base preparada para modelagem |
| `dicionario_variaveis_modulo4.csv` | Dicionário das variáveis |
| `decisoes_tratamento_modulo4.md` | Registro das decisões de tratamento |

## Tratamentos realizados

- Padronização dos nomes das colunas;
- Conversão dos tipos de dados;
- Tratamento de valores ausentes;
- Padronização de categorias;
- Criação da variável-alvo `acidente_fatal`;
- Preparação das bases analítica e modelável;
- Documentação das variáveis e decisões de tratamento.

## Resultado

A base bruta foi transformada em conjuntos de dados estruturados para **análise e modelagem**, com as etapas de tratamento devidamente documentadas.
