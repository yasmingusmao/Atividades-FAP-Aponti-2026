# 📊 Unidade 2 — Tratamento e Análise dos Dados

Nesta unidade, foram desenvolvidas atividades voltadas à **organização, tratamento e exploração dos dados**, utilizando o Microsoft Excel como principal ferramenta de análise.

## 🎯 Objetivo

Preparar uma base de dados para análise e utilizar recursos do Excel para explorar as informações, identificar padrões e gerar visualizações que auxiliem na interpretação dos dados.

A atividade permitiu aplicar conceitos de **organização de dados, dicionário de variáveis, tabelas dinâmicas e visualização de dados**.

## 📚 Atividade desenvolvida

Foi elaborado um arquivo `.xlsx` estruturado em diferentes abas, reunindo as etapas de preparação e exploração da base de dados.

O arquivo contém:

- **Base de dados:** organização dos dados em formato de tabela, facilitando sua manipulação e análise;
- **Dicionário de variáveis:** descrição e identificação das variáveis presentes na base;
- **Tabelas dinâmicas:** exploração dos dados por meio de diferentes cruzamentos e agregações;
- **Gráficos:** visualização dos resultados obtidos a partir das tabelas dinâmicas;
- **Observações:** registro de percepções, padrões e informações relevantes identificadas durante a análise.

## 🧠 Aprendizados

Nesta etapa, foi possível compreender a importância de **organizar e conhecer a estrutura dos dados antes de realizar análises mais aprofundadas**.

A construção do dicionário de variáveis contribuiu para compreender o significado das informações disponíveis, enquanto as tabelas dinâmicas possibilitaram realizar diferentes perspectivas de análise sobre a base.

A criação de gráficos também permitiu perceber como a **visualização de dados pode facilitar a identificação de padrões e a comunicação dos resultados**.
